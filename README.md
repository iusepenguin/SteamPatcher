Steam Patcher for NixOS

Utility designed for NixOS to manage and fix non-Steam game shortcuts. Built with python and  packaged as a nix flake.

Adding non-Steam games (like those from Heroic or Lutris) on NixOS often results in broken launch paths or missing icons in Steam. Steam Patcher safely parses your `shortcuts.vdf` configuration, rewrites paths to utilize NixOS-specific compatibility layers, and automatically injects missing icons.

Features 

The application operates directly on Steam's binary VDF files. Here is exactly what happens:

`_backup_vdf()` (Failsafe ): Before any modification, app generates an automatic, timestamped backup of your `shortcuts.vdf` file (e.g., `shortcuts.vdf.heroic_backup_20260722_210500.bak`). 
`_run_sgdb_fetcher()` (Icon Injection Engine): Scans all user directories within `~/.local/share/Steam/userdata` and parses the binary shortcut data. It isolates entries lacking icons and queries the SteamGridDB API (`_fetch_sgdb_icon()`) to find matching IDs. It then downloads the optimal PNGs, converts them if necessary, saves them to your local `grid` folder, and injects the new paths back into the VDF payload.
`_run_heroic_fix()` (NixOS Path Resolution): Directly addresses the library conflict issues on NixOS. It targets shortcuts generated by the Heroic Games Launcher and aggressively rewrites the `Exe` path to route through `/run/current-system/sw/bin/steam-run heroic --no-gui --no-sandbox`. It also strips conflicting `LD_PRELOAD` variables to ensure games launch from the SteamOS (Gamescope).
`_run_lutris_fix()`: Prepares the VDF configuration for Lutris shortcut fix and path correction.

Installation:
Steam Patcher is distributed as a nix flake.
Add the repository to your flake inputs:

```nix
  inputs = {
    nixpkgs.url = "github:nixos/nixpkgs/nixos-unstable";
    
    steam-patcher = {
      url = "github:minimalistFW/SteamPatcher";
      inputs.nixpkgs.follows = "nixpkgs";
    };
  };
